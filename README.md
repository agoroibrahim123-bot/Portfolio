# Ibrahim Agoro — Tech Journey Portfolio

React + Vite portfolio with interactive sections and a live GitHub repository feed.

## Add your photo
Put your photo at `public/profile.jpg`.

## Run
npm install
npm run dev

## Production build
npm run build

## Publish
Push to GitHub, then import the repository into Vercel. Vercel will build and publish the site, and future pushes can trigger deployments.
